# diceコマンド
![test](https://github.com/1tsu-git/homework/actions/workflows/test.yml/badge.svg)

６面ダイスを振るコマンドです。合計値を足すことができます。

例　dice 2　
12　3

## 必要なソフトウェア
- Python
  - テスト済みバージョン: 3.10〜3.14

## テスト環境
- Ubuntu 24.04 LTS
